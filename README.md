# AI Career Research

A VitePress research website exploring emerging roles in the artificial intelligence industry, including Forward Deployed Engineer, AI Engineer, LLM Engineer, AI Agent Engineer, and AI Solutions Architect.

**Website:** https://mishkhurshid.github.io/ai-career-research/

> The website link will become live after GitHub Pages is enabled and the deployment succeeds.

## Research topics
- Emerging AI job titles and responsibilities
- Required technical and interpersonal skills
- Comparisons of AI career paths
- Industry trends and research sources

## Run locally
Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run docs:dev
```

## Build
```bash
npm run docs:build
npm run docs:preview
```

## Deploy
This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`. In **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**. Pushes to `main` then deploy the site.

## Research note
AI job titles vary between employers. These pages describe typical responsibilities and are not a substitute for reviewing individual job postings.

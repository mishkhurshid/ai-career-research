# AI Career Comparison

| Role | Main focus | Typical deliverables |
| --- | --- | --- |
| Forward Deployed Engineer | Customer-specific implementation | Integrated, deployed solutions |
| AI Engineer | Building AI-powered applications | Product features and services |
| LLM Engineer | Language model applications | RAG systems and LLM pipelines |
| AI Agent Engineer | Tool-using, multi-step AI systems | Agent workflows and evaluations |
| AI Solutions Architect | End-to-end technical design | Architecture and implementation plans |

## Questions to ask when comparing postings

1. Is the role primarily research, product engineering, infrastructure, or customer delivery?
2. Does it require training models, or integrating existing models?
3. What programming languages and cloud tools are named?
4. How much experience is required?
5. What are the security, evaluation, and deployment expectations?

These are broad comparisons, not universal definitions.

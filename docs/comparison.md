# AI Career Comparison

| Role | Main focus | Typical deliverables |
| --- | --- | --- |
| Forward Deployed Engineer | Customer-specific implementation | Integrated, deployed solutions |
| AI Engineer | Building AI-powered applications | Product features and services |
| LLM Engineer | Language model applications | RAG systems and LLM pipelines |
| AI Agent Engineer | Tool-using, multi-step AI systems | Agent workflows and evaluations |
| AI Solutions Architect | End-to-end technical design | Architecture and implementation plans |

## Questions to ask when comparing postings

1. Is the role primarily research, product engineering, infrastructure, or customer delivery?
2. Does it require training models, or integrating existing models?
3. What programming languages and cloud tools are named?
4. How much experience is required?
5. What are the security, evaluation, and deployment expectations?

These are broad comparisons, not universal definitions.

## Which role might fit my interests?

| If you prefer... | Consider exploring | One thing to test |
| --- | --- | --- |
| Meeting customers and coding solutions for their workflows | Forward Deployed Engineer | Can I turn a vague client request into a working demo? |
| Building reusable product features | AI / Applied AI Engineer | Do I enjoy full-stack development and product iteration? |
| Experimenting with retrieval and model behavior | LLM Engineer | Can I measure answer quality and identify failures? |
| Building automated multi-step workflows | AI Agent Engineer | Can I make a tool-using agent safe and reliable? |
| Making high-level technical decisions | AI Solutions Architect | Can I explain architecture and tradeoffs clearly? |
| Improving deployment, uptime, and monitoring | AI Platform / MLOps Engineer | Do I enjoy infrastructure and operational debugging? |

These are **exploration prompts**, not a personality test or a guarantee of job fit.

## How to make a tentative choice

Choose **two roles**, not one. For each, read an actual [employer description](/job-levels), identify three recurring skills, and try one small project from the [Portfolio Roadmap](/portfolio-roadmap). After building, ask yourself whether you enjoyed the daily work—not just the title.

For a student interested in both people and software, **FDE versus Applied AI Engineer** is a particularly useful comparison: the first emphasizes customer-specific deployment, while the second often emphasizes reusable AI product features.

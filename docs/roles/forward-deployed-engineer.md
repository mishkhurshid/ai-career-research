# Forward Deployed Engineer (FDE)

*Career research | Reviewed November 5, 2026*

## What is a Forward Deployed Engineer?

A Forward Deployed Engineer is a hands-on software engineer who works closely with a customer to understand a real business problem, build a technical solution, integrate it into existing systems, and help get it running reliably. In AI companies, this can mean deploying AI applications and agent-based workflows.

Unlike a traditional software engineer focused on a shared product, an FDE often focuses on the needs of particular customers and brings lessons from those deployments back to product teams. [Palantir explains this distinction in its early-career guide](https://www.palantir.com/careers/students-and-early-talent/).

## Typical responsibilities

- Meet with customers and translate their workflows into technical requirements.
- Design and code applications, integrations, and AI-powered workflows.
- Build prototypes, evaluate results, and deploy working systems.
- Test reliability, security, privacy, and performance.
- Troubleshoot production issues and improve the solution.
- Communicate results and tradeoffs to both technical and nontechnical teams.

## A portfolio project I could build

### AI Financial Document Navigator

**Problem:** Financial or billing documents can be difficult for users to understand.

**Proposed solution:** Build a web app that accepts *sample or synthetic* documents, extracts important details, explains unfamiliar terms, and identifies questions a user may want to ask. Include citations back to the source document, human review, and a clear statement that it is not financial or legal advice.

**What it would demonstrate:**
1. Customer problem discovery and written requirements.
2. Python backend and an accessible web interface.
3. Document processing and optional LLM integration.
4. Evaluation on a small set of test documents, including difficult cases.
5. Secure handling of files and a working deployment.
6. A README with screenshots, architecture, limitations, and testing results.

This is a **proposed portfolio project**, not a completed application.

## My research takeaway

This career interests me because it combines building software with understanding people's problems. An FDE needs to do more than write code: they must ask good questions, collaborate with customers, test whether a solution actually works, and explain the results.

The OpenAI examples are experienced-level roles, so they are not necessarily entry-level targets. A practical starting path would be to strengthen software engineering, APIs, databases, AI application development, and deployment skills, then build a portfolio showing end-to-end delivery.

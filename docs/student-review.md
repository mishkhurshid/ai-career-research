# Student Usability Review: Choosing an AI Career

*November 5, 2026 · Scenario-based review*

> **Method:** This is a simulated walkthrough from the perspective of a hypothetical NJIT student exploring AI careers. It is not a real student interview or a verified browser usability test. Findings are based on reviewing the website's source pages, navigation configuration, and research content.

## Student scenario

“I am an NJIT student with some programming experience. I know AI is growing, but I don't know whether I want to build AI apps, work directly with customers, or design technical systems. I want to leave this site with one career to investigate and a realistic next project.”

## Walkthrough

1. **Home:** I understand the broad purpose, but the main buttons send me to role descriptions and comparisons. There is no obvious “I'm a student—where should I start?” path.
2. **Emerging AI Roles:** The definitions help, but the roles are all text-heavy and I cannot click directly from each summary to a dedicated role page. FDE has a deeper page, while the other roles don't yet.
3. **Comparison:** The table explains outputs, but it does not compare daily work, customer contact, coding intensity, or likely entry points—things I need to choose.
4. **Jobs by Level:** Real employer examples are valuable, especially internships and new-graduate jobs. But this page is long; I need quick filters or a summary table to jump to a career level or role. Some listings link to general career directories rather than the exact job description.
5. **Skills:** The skills list is useful but broad. I cannot tell which skills matter most for *my chosen role* or which one to learn next.
6. **Decision:** Based on the information currently presented, I would shortlist **Forward Deployed Engineer** and **Applied AI Engineer**. FDE sounds interesting because I could combine coding with understanding a customer's problem. Applied AI Engineer is appealing because it is more product-building focused. I would not treat either as a final career choice yet.

## Issues and improvements

| Priority | Issue | Why it matters to a student | Suggested change |
| --- | --- | --- | --- |
| High | No clear student starting path | I don't know which page to visit first | Add “Start here: choose your AI path” on the homepage |
| High | Uneven role depth | FDE is detailed, but other roles are brief | Add dedicated pages for Applied AI, Agents, LLM, and Solutions Architect |
| High | Job postings not easy to scan | I must scroll through long descriptions | Add a summary table and links by career level |
| High | Some links go to employer directories | Hard to verify the exact example | Prefer direct posting URLs; label directory links |
| High | No role-to-project mapping | I can't tell what to build for my target role | Add a portfolio roadmap with evidence mapped to employer requirements |
| Medium | No decision support | I understand definitions but can't choose | Add “Which sounds like you?” comparison questions |
| Medium | Little indication of geographic fit | NJIT students may prefer NYC/NJ opportunities | Add location and work arrangement to the summary table |
| Medium | Missing posting status/review date per role | Listings may expire | Record last-checked date and whether active status was verified |

| Low | No simple glossary | RAG, MLOps, evaluations may be unfamiliar | Add definitions on first use and a glossary |

## Hypothetical student's career choice

**First choice to explore: Forward Deployed Engineer.**

**Why:** I like the mix of programming, AI systems, and working with people to solve concrete problems. I would want to learn whether I enjoy client meetings and frequent changes in project requirements.

**Second choice: Applied AI Engineer.**

**Why:** It also involves building useful AI applications, but may be a better fit if I prefer spending more time implementing product features than working directly with customers.

**What would help me decide:** Two small projects—one customer-driven AI workflow with written requirements and a demo, and one independent AI product feature with tests and evaluation. Comparing the experience of building each would tell me more than job titles alone.

## Suggested portfolio roadmap

| Stage | Project | Skills demonstrated | Evidence to publish |
| --- | --- | --- | --- |
| 1 | Python API + small web interface | Python, HTTP APIs, Git, debugging | Source code, README, tests, screenshots |
| 2 | Document question-answering tool using synthetic data | LLM integration, retrieval, citations | Working demo, evaluation examples, limitations |
| 3 | Customer-style AI workflow case study | Requirements discovery, stakeholder communication, integration | Problem statement, architecture, demo, decisions |
| 4 | Production-readiness improvement | Reliability, monitoring, security, evaluation | Test report, failure analysis, deployment guide |

These are proposed learning projects, not completed work or requirements imposed by a particular employer.

## What I would change first

1. Put a prominent **Start Here** link on the homepage.
2. Create a scannable **Choose Your AI Role** page with practical questions and role matches.
3. Add a clear **Student Portfolio Roadmap** linked to the real job research.
4. Improve direct job-posting links, freshness labels, and career-level navigation.
5. Conduct a real browser and mobile usability check, followed by feedback from an actual NJIT student.

## Review limitations

This is an analytical role-play based on the repository content, not an observed human usability session. It does not establish that the live site's links, mobile layout, or interactive behavior were tested. Those should be verified separately.

# Start Here: Choose an AI Career

**You don't need to choose a career today.** Compare two roles and try one project.

## 1. Pick a direction

| If you enjoy… | Explore |
| --- | --- |
| Coding and solving customer problems | [Forward Deployed Engineer](/roles/forward-deployed-engineer) |
| Building AI features | [Applied AI Engineer](/roles/) |
| Testing language models | [LLM Engineer](/roles/) |
| Automating multi-step tasks | [AI Agent Engineer](/roles/) |
| Designing or operating systems | [AI Solutions Architect / MLOps](/roles/) |

## 2. Check real job descriptions

[Compare internships, entry-level, and experienced jobs →](/job-levels)

Check the **employer, date, tasks, experience, location, deadline, and availability**. An employer's posting—not a general role summary—is the source of truth.

## 3. Choose one project

[See the portfolio roadmap →](/portfolio-roadmap)

Ask yourself:
- Which tasks sound interesting?
- Which skills do I already have?
- Which two skills should I learn next?

**Next step:** Document a small project with code, tests, and a clear explanation.

*The [student review](/student-review) is a simulated walkthrough, not a real interview.*
